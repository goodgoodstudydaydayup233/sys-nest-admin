
## 📋 通用标准管理页面生成提示词
### 一、技术栈与工程规范
```
- 框架：Vue 3.5 + Composition API（<script setup lang="ts">）
- 构建工具：Vite 8
- UI 组件库：Element Plus 2.13+（自动导入，无需手动 import 组件）
- 图标库：@element-plus/icons-vue（需手动 import 具体图标）
- 类型系统：TypeScript 6.0+，严格模式
- 状态管理：Pinia（仅在页面需要全局状态时使用）
- 包管理器：pnpm
```
### 二、代码风格规范
```
- 分号：不加分号（semi: false）
- 引号：单引号（singleQuote: true）
- 行宽：100 字符（printWidth: 100）
- ESLint 规则：vue/multi-word-component-names 已关闭，@typescript-eslint/
no-explicit-any 已关闭
- 代码注释：所有函数、变量、类型必须使用 JSDoc 注释说明用途，函数使用 
@description、@param、@example 标签
- 文件编码：UTF-8
- 缩进：2 空格
```
### 三、页面标准布局结构（从上到下）

### 四、Script 代码组织结构（按顺序）
```

 * - DELETE /xxx/batch             删除（如有）
```

### 五、API 接口层规范
```
文件位置：src/api/{module}/xxx.ts

结构：
- 类型定义区域：定义 XxxVo（视图对象）、QueryXxxParams extends PageParams（查询
参数）、
  CreateXxxParams（创建参数）、UpdateXxxParams（修改参数）
- API 对象区域：export const xxxApi = { ... }，每个方法返回 Promise<T>

接口调用约定：
- 所有接口自动解包 data 字段，业务层直接使用返回值
- GET 列表返回 PaginationResult<XxxVo>（包含 list 和 total）
- POST/PUT/DELETE 返回 void（成功即完成，失败由拦截器统一提示）
- 文件上传使用 FormData + isUpload: true
- 错误处理：try-catch 中 catch 为空（错误已由请求拦截器统一 ElMessage.error 提
示）

类型导出：
在 src/api/{module}/index.ts 中统一聚合导出 API 和类型
```
### 六、TypeScript 类型规范
```
文件位置：src/api/{module}/xxx.ts 中定义

通用类型（全局）：
- PageParams：{ page: number; pageSize: number }
- PaginationResult<T>：{ list: T[]; total: number }

业务类型命名规范：
- XxxVo：视图对象（后端返回给前端的数据结构，继承 id/createdAt/updatedAt）
- QueryXxxParams extends PageParams：查询参数
- CreateXxxParams：创建参数
- UpdateXxxParams：修改参数

类型要求：
- 每个接口类型必须有 JSDoc 注释
- 每个字段必须有 /** 注释说明 */
- 可选字段使用 ? 标记
- 枚举值字符串类型（如 status: '0' | '1'）
```
### 七、路由配置规范
```
文件位置：src/router/modules/{module}.ts

结构：
- 使用 DefaultLayout 作为父级布局组件
- 父级 path: '/{module}'，设置 redirect 到第一个子路由
- 子路由 path 使用相对路径（如 'user'）
- 子路由 name 使用 PascalCase（如 'UserManage'）
- 所有组件使用动态 import 懒加载
- meta 必须包含 title 和 icon
- 在 src/router/index.ts 中导入并注册路由模块
```
八、样式规范
```
- 使用 <style lang="css" scoped>
- 不使用 SCSS/Less（项目已有 sass-embedded 但页面样式保持 CSS）
- 使用 Element Plus CSS 变量（var(--el-xxx)）确保主题一致性
- .page-container: padding: 20px; display: flex; flex-direction: column; 
gap: 16px
- 筛选区使用 .search-bar 扁平容器（全局样式已定义：无背景、无边框、无阴影，
padding: 0 0 16px），不包裹 el-card；由于 .page-container 已有 gap 间距，
页面内可声明 padding-bottom: 0 避免重复留白（与 /system/user 保持一致）
- 表格不包裹 el-card，直接使用裸 el-table
- 表格无边框：不传 border 属性，全局样式已移除竖向列分隔线（含固定列），
仅保留行间分隔线
- 表头淡灰色（背景 #f8f8f8、字色 #666、字重 600）由全局样式统一处理，
页面无需重复定义
- 分页区 .pagination-wrapper（全局已定义：flex + justify-content: flex-end 
+ padding: 16px 0），与表格分离，不共用卡片
- .table-action-bar: flex + align-items: center + justify-content: 
space-between
- 状态选择器：class="xxx-select"，宽度控制为 180px
- 文本占位符：class="text-placeholder"，color: var
(--el-text-color-placeholder)
- 多个 tag 并排：使用 .xxx-tag + .xxx-tag { margin-left: 4px }
```
九、交互行为规范
```
搜索行为：
- 点击"搜索"或回车 → page 重置为 1 → 调用 fetchList
- 点击"重置" → 清空所有筛选字段为 undefined → page=1, pageSize=10 → 调用 fetchList

分页行为：
- 切换每页条数 → 直接调用 fetchList（queryParams 已通过 v-model 自动更新）
- 切换页码 → 直接调用 fetchList
- 查询成功后清空 selectedRows

新增行为：
- 点击"新增" → dialogType='create' → 重置 formData 为初始值 → 打开弹窗
- 密码字段仅新增时显示（v-if="dialogType === 'create'"）
- 提交成功 → 关闭弹窗 → ElMessage.success → 刷新列表

编辑行为：
- 点击"编辑" → 先调用 getUserDetail 获取详情 → 回填 formData → dialogType='edit' → 打开弹窗
- 编辑时密码字段不显示
- 提交成功 → 关闭弹窗 → ElMessage.success → 刷新列表

删除行为：
- 单条删除 → el-popconfirm 二次确认 → 调用接口 → ElMessage.success → 刷新列表
- 删除 → ElMessageBox.confirm 二次确认 → 调用接口 → ElMessage.success → 清空选中 → 刷新列表

弹窗关闭：
- @close → resetFields 清除校验 → 重置 formData 和相关 ref

表单校验：
- 必填字段 { required: true, message: '中文提示', trigger: 'blur' }
- 长度限制 { min: x, max: y, message: '长度说明', trigger: 'blur' }
- 提交前调用 formRef.validate().catch(() => false)
```


十、关键注意事项
1. 接口返回值已自动解包 data，直接使用返回值，不需要 .data
2. 所有异步操作使用 async/await，catch 块留空（拦截器已处理错误提示）
3. 表单重置使用 Object.assign 而非直接赋值（保持 reactive 引用）
4. 弹窗打开后需 nextTick(() => formRef.value?.clearValidate()) 清除上次校验状态
5. 编辑回填时使用 ?? '' 处理可选字段的 null/undefined
6. 不添加冗余注释，只保留 JSDoc 格式的文档注释
7. 图标需从 @element-plus/icons-vue 手动导入
8. 组件无需手动导入（Element Plus 已配置自动导入）
9. 删除/危险操作必须有二次确认（el-popconfirm 或 ElMessageBox.confirm）
10. 表格操作列 fixed="right"，多选列 width="50"
11. 筛选区/表格区不使用 el-card 包裹：筛选区用 .search-bar 扁平 div，
    表格用裸 el-table
12. 分页与表格分离：分页放 .pagination-wrapper 独立容器，不与表格共卡片
13. 表格不传 border 属性（全局样式已移除竖向列分隔线、保留行间分隔线）；
    表头淡灰色由全局样式统一处理，页面无需重复声明
14. 所有文件路径遵循项目目录结构规范
